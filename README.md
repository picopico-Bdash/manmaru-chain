# まんまるチェイン

丸くてかわいいブロックを4つつなげて消す、連鎖パズルゲームです。ブラウザだけで遊べます。

## 遊ぶ

👉 https://picopico-bdash.github.io/manmaru-chain/

## 操作

| | PC（キーボード） | スマホ（タッチ） |
|---|---|---|
| 移動 | ← → | 盤面を左右にスワイプ / ← → ボタン |
| 回転 | ↑・X（右）/ Z（左） | 盤面をタップ（右半分で右回転・左半分で左回転）/ ↺ ↻ ボタン |
| ゆっくり落とす | ↓ | 盤面を下に押さえたまま / ↓ ボタン |
| 一気に落とす | Space | ⤓ ボタン |

スマホ（またはタッチ操作の端末・幅の狭い画面）では、盤面の右にスコアと「つぎ」、下に操作ボタンを並べたレイアウトに切り替わります。

## ルール

- 同じ色を4つつなげると消えます。消えたあとに落ちてまたつながると「れんさ」になります。
- **大まんまる**: 同じ色が2×2でつながると、消えずにぷるんと合体して大きな「大まんまる」になります。大まんまるは4個ぶんとして数え、となりに同じ色の5つ目が来ると消えて、左右にいるスライム（斜めに接するものも）をぽよんと外側の列へ1マス弾き飛ばします（となりの列が自分の段から2段以上積まれているときは、積み上がらずにその場にとどまります）。
- **ごきげん度**: 置いたスライムは10秒ごとに「にこにこ → ふつう → ぶすっ」と表情が変わり、30秒たつと固まって**石まんまる**になります。同じ色とくっつく（結合する）と、つながったかたまり全体のごきげんが「にこにこ」に戻ります。石は色のつながりが切れていて、となり（斜めも）で大まんまるを消したときだけ壊せます。大まんまるはずっと「にこにこ」のままで、石になりません。

## 素材の作り直し

- `tools/blender/render_extras.py` … 大まんまる（`sprites/big_*.png`）と石まんまる（`sprites/stone.png`）を Blender でレンダリング
  （`blender -b -P tools/blender/render_extras.py`、または `pip install bpy` して `python tools/blender/render_extras.py`）
- `tools/make_noface_atlas.py` … 表情を描き分けるための、目を消したアトラス（`tiles/atlas_noface.png`）を作成
