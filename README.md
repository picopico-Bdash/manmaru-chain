# まんまるチェイン

丸くてかわいいブロックを4つつなげて消す、連鎖パズルゲームです。ブラウザだけで遊べます。

## 遊ぶ

👉 https://picopico-bdash.github.io/manmaru-chain/

## 操作

| | PC（キーボード） | スマホ（タッチ） |
|---|---|---|
| 移動 | ← → | 盤面を左右にスワイプ / ← → ボタン |
| 回転 | ↑・X（右）/ Z（左） | 盤面をタップ（右半分で右回転・左半分で左回転）/ ↺ ↻ ボタン |
| ゆっくり落とす | ↓ | 盤面を下に押さえたまま / ↓ ボタン |
| 一気に落とす | Space | 盤面を下にはじく / ⤓ ボタン |

スマホ（またはタッチ操作の端末・幅の狭い画面）では、盤面の右にスコアと「つぎ」、下に操作ボタンを並べたレイアウトに切り替わります。
